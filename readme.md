# PortSwigger Web Security Academy: Writeups & Notes

Hey there! This repo is my personal logbook for the PortSwigger Web Security Academy labs. I'm working through these to get hands-on practice with real-world web vulnerabilities and to sharpen my Burp Suite skills. 

I try to knock out a lab whenever I can and document the process. It’s a great way to solidify the techniques and keep a record of my progress. 

> **Disclaimer:** These writeups are strictly for educational purposes on PortSwigger's dedicated lab environment. Never test these techniques on systems you don't have explicit permission to test.
